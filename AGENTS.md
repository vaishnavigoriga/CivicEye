
# CivicEye - Project Instructions

Build a complete, professional full-stack civic grievance management platform.

## Technology Stack
- Frontend: React, Vite, TypeScript, Tailwind CSS
- Backend: Node.js, Express, TypeScript
- Database: MongoDB with Mongoose
- AI: Gemini API, with a working mock fallback
- Maps: Leaflet and OpenStreetMap
- Charts: Recharts

## Core Features
- Citizen grievance reporting using text, images and voice.
- AI classification and severity analysis.
- English, Telugu and Hindi support.
- Duplicate complaint detection.
- Hyderabad complaint map.
- Public analytics dashboard.
- Admin dashboard and department assignment.
- Complaint status tracking and timeline.
- Resolution evidence uploads.
- Demo login for citizens and administrators.

## Development Rules
- Use a clean, modular architecture.
- Keep frontend and backend separate.
- Use environment variables for secrets.
- Never expose API keys in frontend code.
- Validate API inputs and handle errors.
- Use realistic but fictional demo data.
- Make the application functional, not just visually attractive.
- Every visible button should have a working action.
- Include a demo mode that works without an AI API key.
- Clearly label simulated AI results.
- Never claim that demo complaints are submitted to real government departments.

## Important Workflow
- First inspect the workspace and prepare an implementation plan.
- Do not start coding until the plan is reviewed and approved.
- Build one module at a time.
- Test each module before moving forward.
- Do not delete existing files or run destructive commands without approval.
- Explain important setup and terminal commands.
